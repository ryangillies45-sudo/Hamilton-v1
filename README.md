# Hamilton Pixel Documentary

A 30-second, 900-frame (30 fps, 1920×1080) pixel-art tribute to Lewis Hamilton's 20 Formula 1 seasons, 2007–2026, built with Remotion.

**Status:** planning. Nothing is built yet. The production plan awaits approval: [docs/production-plan.md](docs/production-plan.md).

Historical facts and imagined content are kept strictly apart. The Rwanda 2030 finale is an imagined scenario and is labelled IMAGINED on every frame.

This repository is public. Music, photographs and other licensed reference material are never committed.
